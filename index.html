The Iron Citadel

One dungeon level brief, The Iron Citadel Infiltration, built three ways in Unity 6 with the same Synty POLYGON dungeon art: through our level framework, and by two AI models working cold from one prompt in an empty project. The same scorer measured all three.

The web builds need a desktop browser. Click the page to capture the mouse. Then use WASD to walk, the mouse to look, E to open a door, M for the map and L for the headlight. The headlight is only in the web builds: the browser's light limits would leave many rooms dark.
