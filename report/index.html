Framework vs. cold prompts

One level brief: eleven themed rooms on a 4 × 4 grid of 45 m tiles, with a gallery, a throne stage, a gated armory and a secret vault. Fable 5.1 and Opus 5.5 each built it cold in Unity from the three Synty dungeon packs. Ours built it through the framework twice: as a themed-room level and as a pattern-tile level. Every build is a Unity scene, walked by the same first-person controller and scored by the same conformance kit.

At a glance

The scores come from one kit: ten automatic checks against level.json, plus one judged by eye. The walker is a person-sized CharacterController (radius 0.35 m, height 1.8 m, step 0.3 m). Costs are at API list price; both cold runs actually ran on a subscription.

Read with care

  • Flat and nested builds count prefabs differently. A cold run's outermost-prefab count is its piece count; ours is not. To compare variety, use the different-pieces, leaf-asset or mesh rows.
  • The patterns level is a different size (300 × 400 m against eleven 45 m cells), so its renderer, triangle and collider totals are not like-for-like.
  • Scene file size understates ours. Our content lives in prefab files; the "level data on disk" row adds them back. Those room and set-piece prefabs come from pre-built libraries and were not made for this level.
  • Synty textures are atlases, so every build has few materials and textures. Those rows show which packs were used more than how varied the look is.
  • Nothing is baked. No build has lightmaps or probes. The patterns level's 309 torches are meshes only: it is lit by one directional light. The cold runs each add a post-processing volume; ours rely on the project's default profile.
  • Not measured: draw calls and frame time.
  • The framework is not counted as code for ours. It is MacroTileBuilder, PrefabSynthesis and the room and set-piece libraries, all of which existed before this brief.
  • The brief favours the framework. It was written to what the framework already has, so treat this as a showcase brief, not a neutral benchmark.
